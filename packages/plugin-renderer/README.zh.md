# @deepseek-ai/dsh-convax-plugin-renderer

[English](README.md) | 中文

## 概述

在多个可保存的画布上排列文件、文件夹、应用窗口与对话。每个 Chat 卡片通过现有对话流、输入框和控件创建、分叉及切换 DSH 会话。浏览器式标签页将打开的画布和视口位置保留为窗口偏好。关闭标签页保留画布、草稿和运行中的会话；移除引用保留原文件。此可选 Bundle 将主工作区切换为画布，同时保留原生设置和插件管理入口。

## 使用本包

本 Bundle 的[配置补丁](cordis.patch.yml)分别挂载[画布 Host](../plugin-host/README.zh.md)、画布 Renderer、[默认节点 Host](../plugin-inernal-nodes-host/README.zh.md)及[默认节点界面](../plugin-inernal-nodes-renderer/README.zh.md)。它依赖已启用原生客户端服务的 Web 或 Desktop 配置。停用画布 Renderer 后恢复原生工作区。仅停用节点界面时，画布、已保存节点和连线以占位保留，原生 DSH 任务继续运行。默认节点使用与第三方节点相同的公开扩展 API。

从源码检出目录开发 Desktop 时，运行 `pnpm --filter @deepseek-ai/dsh-convax-plugin-renderer run desktop:dev`；完成构建后，`pnpm --filter @deepseek-ai/dsh-convax-plugin-renderer run desktop` 复用已有产物。脚本在外层仓库存在 `.env` 时读取它，保留已有环境变量的值，再从 `libs/dsh` 运行 DSH 原有的 Desktop 命令。Convax 包装器将外层仓库 `.convax` 的绝对路径设为 `DSH_HOME`，将 `.convax/electron-user-data` 设为 `DSH_DESKTOP_USER_DATA_DIR`。所选 profile 保留已安装插件。这些启动路径来自启动环境，不通过项目 `.env` 发现。原生 [Desktop 开发默认目录](../../libs/dsh/apps/desktop/README.zh.md#develop)保持独立。

画布标签、左下角视图控件和底部居中的创建入口采用紧凑的文字、图标与间距。画布自有图标使用 [Lucide React](https://lucide.dev/guide/react) 的具名导入；嵌入的原生 DSH 视图保留其自有图标。悬停画布标签或创建按钮时只增加背景，文字颜色保持不变。

画布表面和资源分类颜色遵循 DSH 的浅色、深色及跟随系统外观。资源与 Chat 连接点使用相同主题填充、表面描边和尺寸；图选区及连线预览使用同一语义强调色。键盘焦点环保留主题按指针输入方式抑制绘制的行为，未提供焦点色覆盖时使用主题语义强调色。文档预览保留源内容颜色。

右上角工作区菜单中的**全部画布**打开可搜索的管理面板，按画布和已归档分组，展示节点与聊天数量，并为各画布提供操作菜单。两组画布均可通过**重命名画布**修改标题，不会打开画布或改变归档状态。归档会关闭对应标签，不停止对话或改变 Session 归档状态；**撤销**会将画布恢复到未归档列表。取消归档后可再次打开画布。**复制画布**打开独立副本，卡片与连线使用新标识，保留文件路径和位置；Chat 使用全新会话，不复用原有对话或草稿。**永久删除…**需要确认，会清除画布及撤销记录；原始文件和 Session 历史保留，正在运行的对话会停止并归档。删除失败时保留画布，并提供使用原操作标识的**重试**入口。

顶部的**活动**汇集各画布的完成及待处理提醒。角标显示未读数量；打开浮层保持未读。选择提醒会重新打开所属画布，选中并展开目标 Chat 的 thread，将卡片移入视野并短暂高亮；卡片可容纳时保留缩放比例。只有定位成功才标为已读。**全部已读**清除未读角标，不回答待处理请求。已读的待处理提醒保留到请求解决，每个 Session 最新的完成提醒在本次客户端运行期间保留。移除 Chat 会清除其活动记录。

顶栏的**自动化**在画布上方打开 DSH 的[任务管理器](../../libs/dsh/packages/client/ui-schedule/README.zh.md)，包含其他画布以及尚无 Chat 卡片的 Session 的任务。选择任务可查看原生规则和已保存的发送记录；**关联会话**打开已有画布、选中 thread 并定位 Chat。可用且尚未绑定的 Session 会在当前画布成为一张 Chat 卡片，保留已有历史与任务关联。**新建**使用画布默认工作目录在当前画布创建 Chat，并在原生输入框中准备自动化请求，由用户补充并发送。有活动任务的 thread 在标签控件旁显示原生提醒时钟；任务详情使用该 thread 现有的右侧工具面板。

顶栏包含浏览器式画布标签、新建画布操作、活动、自动化和工作区菜单。在 macOS Desktop 中，它通过框架的[集成标题栏支持](../../libs/dsh/packages/client/ui-layout/README.zh.md#window-chrome-seat)与原生标题栏共用一行。每个标签包含标题和关闭操作。未选中标签的关闭操作在悬停或键盘聚焦时显示；不支持悬停的设备始终显示关闭操作。横向拖动标签标题可以调整顺序。标签跟随指针移动，邻近标签会平滑让位；拖到两端停留时，标签栏会自动滚动。松开标签时，通过动画归位到保存的位置。松手保存排序，按 Escape 取消。也可以聚焦标签后按 Alt+ArrowLeft 或 Alt+ArrowRight 通过键盘移动标签。重新打开客户端后会保留排序。双击标签标题可以重命名画布。右侧工作区菜单只提供**全部画布**、原生**设置**和**插件**入口。画布专属操作保留在管理面板各行的菜单中，选择已保存画布可重新打开其标签。**插件**在画布上方的右侧抽屉中打开现有管理界面。关闭抽屉后，当前画布及其视口保持不变。关闭标签页保留已保存画布；删除画布移除其已保存文档。修改失败时保留可见内容并显示错误。

画布占满工作区，底部居中的基础入口为**添加项目**、**添加文件**和**新建聊天**。添加项目通过 DSH 目录选择器选取文件夹并添加文件夹引用；添加文件通过系统文件选择器支持多选。通过选择器添加节点时，起始位置在当前画布视口内，已有坐标和显式拖放坐标保持不变。展开文件卡片可预览内容，也可选中卡片后通过工具栏在画布上方打开更大的预览。从卡片右侧输出连接到左侧输入。悬停或选中连线会高亮连线，并在中点显示剪刀按钮。点击剪刀或按 Delete、Backspace 可以切断悬停连线；没有悬停连线时切断所选连线。编辑控件保留自己的删除按键。悬停或选中连线、或选中其连接的卡片时，流光沿连线向输入端移动；系统设置减少动态效果时关闭该动画。也可以通过所选卡片的工具栏移除卡片；移除引用保留原文件。

选中卡片后，工具栏显示在卡片上方。缩放画布时，工具栏图标保持相同的屏幕尺寸。文件与文件夹工具栏提供放大、**在文件管理器中显示**及**移除引用**；文件夹工具栏还提供**新建聊天**。放大操作打开更大的文件预览，或将文件夹卡片适配到视口中。**在文件管理器中显示**在系统文件管理器中定位文件或文件夹。Chat 工具栏提供聚焦及删除入口。

macOS Desktop 的创建栏提供**应用窗口**，按标题列出运行中窗口，并显示所属应用图标；图标不可用时显示通用窗口图标，不采集缩略图。选择一个具体窗口创建只读镜像卡片。工具栏提供**重新选择窗口**、**新建聊天**、聚焦及移除；展开、折叠和调节尺寸沿用资源卡片。镜像不转发点击、键盘输入或音频。折叠卡片或切换画布只释放其视图，为未发送 reference 保留采集；移除或重新绑定节点、卸载 renderer 时停止采集。副本和客户端重启后需要明确重新选择，不按保存的原生 id 或相同标题自动重连。

断开的卡片提供**重连**和**重新选择窗口**。重连会重试当前 renderer 生命周期内保留的具体窗口，保留卡片、连线及未发送 reference。连接期间禁用两项连接操作。失败后保留操作入口，可以恢复窗口、检查屏幕录制权限后重试。重启或复制后若已没有原窗口身份，重连会打开窗口选择器要求明确选择，不会换成同名窗口。

窗口连接到 Chat 时，向捕获的 thread 草稿插入可删除 reference。从卡片新建 Chat 时使用画布工作目录，并连接窗口。发送时，保留的窗口 reference 采集最新图片，经原生 DSH 附件与文本一起提交。删除 reference 保留连线；已保存连线不恢复已消费的 reference。排队消息保留提交时图片，历史独立于实时窗口保留图片。采集失败恢复原生草稿，不发送旧像素。窗口 reference 不改变 Computer Use 的 preset 或授权。

文件与文件夹卡片的初始宽度为 320px，头部和内容共用不透明底色与圆角边框。头部左侧放展开箭头、类型图标与名称，右侧放元数据；展开内容与头部之间用分隔线区分。卡片不展示完整路径。通过选择器添加或拖入的文件、文件夹卡片初始展开；已有卡片保留展开状态。展开和折叠期间，端口始终挂载在卡片两侧。拖动名称区域可移动卡片。展开的文件夹按需读取并监听各级已打开目录；子文件夹保持折叠，打开时再加载。目录预览初始高度为 240px，可调整尺寸，内容在卡片内部滚动，头部保持可见。选择文件可预览内容。目录读取失败时保留可用条目，并在对应分支显示**重试**。折叠文件夹会释放其展开目录的监听。

文件夹与文档预览初始高度为 240px，音频为 104px，视频初始采用 16:9；已有的预览尺寸偏好优先。音频高度不小于 104px，其他预览不小于 160px，卡片宽度不小于 320px。拖动右下角外侧的手柄可调整卡片宽度与预览高度，也可聚焦手柄后使用方向键。文件、文件夹与窗口卡片共用尺寸手柄，断开的镜像及提供方不可用的占位卡片也可调整尺寸。折叠时只调整宽度，保留展开高度。每个资源卡片在当前窗口内保留展开状态、宽度与预览高度。预览内容在卡片内部滚动。文件预览在卡片内部保留 8px 内边距；音频控件自行提供垂直间距。图片和视频保持原始比例，其他格式保留适合阅读的内部布局。[共享文档渲染器](../../libs/dsh/packages/client/ui-sidebar-documentpreview/README.zh.md#embedded-previews)展示文本、代码、Markdown、静态 HTML、图片、PDF 和表格，不打开 Session 或 Sidebar 标签页。[Host 转换器](../plugin-host/README.zh.md)可用时，Word 与 PowerPoint 显示为 PDF。仅在预览打开期间加载文档内容；读取失败时保留可用内容并提供**重试**。停用预览插件时，卡片保留头部并在本地显示不可用说明。

音频与视频预览通过带版本的 HTTP 字节范围使用浏览器原生播放。悬停时开始预览，移开时暂停。在悬停播放时选择**移开后继续播放**，或暂停时选择**播放**，可以在指针移开、卡片折叠或打开另一张画布后继续播放。**暂停**停止手动播放；后台播放在画布外提供暂停控件。移除或替换来源、停用插件以及关闭客户端时释放播放器。放大预览共享同一播放器和播放位置。两种格式均提供音量和定位操作。浏览器阻止自动播放时提供手动播放入口；不支持的格式提供**使用系统应用打开**，不转码。

音频将播放或暂停、波形和音量按钮放在紧凑的一行内，已播时间和总时长位于波形下方。点击或拖动波形可定位，也可聚焦波形后使用方向键、Home 或 End。波形是唯一的进度控件；加载中或无法解码时，在同一区域使用定位条。逐步解码只保留固定峰值分组和有界的样本复制内存。点击音量图标按需打开滑杆。音频卡片折叠后，在头部保留播放或暂停和时间，共享同一播放器与播放位置。

视频元数据在可用时展示原始分辨率与时长。画面完整显示视频，不裁切内容。播放、进度、时间、音量与全屏共用一条底部浮层。选中卡片，或预览区域悬停、含键盘焦点时显示浮层。全屏、不支持悬停的设备及粗指针设备始终显示。视频暂停时提供居中播放按钮。音量图标通过弹出面板展示滑杆。

在画布左下角选择**触控板**或**鼠标**。触控板模式使用双指滑动平移画布，捏合手势仍用于缩放；鼠标模式保留滚轮缩放和拖动平移。macOS 默认使用触控板模式，Windows 及其他平台默认使用鼠标模式。手动选择会在切换画布标签和重新打开客户端后保留。

键盘焦点位于画布时，按 Cmd/Ctrl+A 全选卡片，方向键将选区移动五个画布单位，Delete 或 Backspace 删除选区。悬停或选中的连线优先删除。每次移动都通过 Host 保存，保存失败时恢复已提交的位置。Escape 清空选区并取消正在进行的节点拖动。Cmd/Ctrl+加号和减号缩放，Cmd/Ctrl+0 适应画布。编辑器、Chat 控件、终端、菜单、弹窗和输入法组合过程保留各自的原生键盘行为。

拖动卡片时，边缘和中心线会吸附到其他卡片，并显示对齐辅助线。多卡片选区保持相对位置。吸附阈值在不同缩放下始终为六个屏幕像素。松手后一起保存对齐的位置；按 Escape 或窗口失去焦点时取消拖动并清除辅助线。

右键画布空白处，可以在该位置添加项目、文件或 Chat。项目创建使用 DSH 组合后的目录选择器，包括网页内选择器和 Desktop 原生选择器；Chat 创建使用画布工作目录。右键已选卡片时操作整个选区，右键未选卡片时仅操作该卡片；打开菜单保持原选区不变。多卡片选区包围盒内的空白处提供同样的选区操作。菜单按目标提供聚焦、移除、全选和适应画布操作。编辑器、Chat 内容和终端保留原生右键菜单。

将连接点拖到画布空白处，可以在该位置选择新建 Chat、项目或文件。创建菜单打开时保留临时连线。新卡片和连线按原连接点的方向一起原子保存。从文件夹输出端创建 Chat 时，以该文件夹作为项目；文件输出端使用文件所在目录。其他来源使用画布工作目录。输入端会在异步选择文件或目录期间保留当时的目标 thread。按 Escape、点击外部或窗口失去焦点时取消待创建连线，不修改图。移除输入框中已添加的引用会保留连线，刷新后也不会重新补回该引用。

Cmd/Ctrl+C 将选中卡片及其内部连线复制到系统剪贴板，Cmd/Ctrl+V 粘贴到当前画布。Cmd/Ctrl+D 复制选区，不改变剪贴板。副本使用新身份，保持相对位置并避开已有卡片。文件引用保留原路径。Chat 副本保留标题、工作目录、尺寸和折叠偏好，并准备独立 thread 和空白草稿。复制连线不会向输入框添加引用。编辑器保留原生剪贴板快捷键。剪贴板读取期间切换画布、图版本变化或按 Escape 时，取消待粘贴操作。

Cmd/Ctrl+Z 撤销图编辑，Cmd/Ctrl+Shift+Z 或 Ctrl+Y 重做。左下角控件和右键菜单提供同样的操作。每次拖动或整组复制记为一次编辑。每张画布在刷新后保留当前窗口已确认的编辑历史，Agent 和其他窗口的改动不进入该历史。撤销保留后续对独立字段的修改，受影响字段已变化时报告冲突。恢复已移除的 Chat 时重新连接原 Session，并取消该次移除造成的归档，已停止的任务保持停止。恢复资源卡片时保留其展开状态及预览尺寸。恢复连线不会向输入框重新添加引用。编辑器保留自身的原生撤销和重做。

一次滚轮手势及其惯性保持开始时选定的画布或内容区。画布导航时，卡片移到指针下方也不会中断。手势从当前方向可滚动的内容区开始时滚动内容；同一次手势到达边界时，不会带动画布。暂停后，下一次手势重新选择操作对象。卡片标题和没有滚动内容的区域操作画布。捏合或 Ctrl 加滚轮跨卡片缩放画布；内嵌文档的缩放按钮仍只调整文档，放大预览保留局部缩放手势。终端、表格和编辑器保留原生滚动。HTML 预览提供明确的进入和退出[内容交互](../../libs/dsh/packages/client/ui-sidebar-documentpreview/README.zh.md#embedded-previews)入口；进入后，内嵌网页接管自身手势，直到退出内容交互。

按住空格拖动，或使用鼠标中键拖动，可从卡片控件或内容区移动画布。输入框或编辑器聚焦时，空格保留文本输入行为。松开指针、按 Escape 或离开应用会结束强制拖动，并保留当前视角位置。

Desktop 中选择的文件和从系统文件管理器拖入的项目均引用其原始路径。多项添加会并排放置卡片，逐个等待版本保存。内联提示会列出不可读项目和已确认的数量；保存结果未确认时会停止添加后续项目。请刷新并检查画布后再试。选择或拖放的项目缺少 Host 路径时会显示相同提示，请使用 Desktop 引用这些本地文件。

选择**新建聊天**直接使用画布工作目录，不打开选择器。[Host](../plugin-host/README.zh.md)为每张画布创建并保留独立目录；已有画布在首次需要时准备目录。在文件夹卡片上选择**新建聊天**时，使用该文件夹路径。已有 Chat 保留原项目目录。目录创建失败时显示错误，图保持不变。Chat 会自动准备首个 thread 并显示原生输入框；已有的空 Chat 在打开时也会自动准备。加载期间保留对话正文卡片的高度和连线端点位置，直到原生对话准备就绪。从文件夹卡片创建 Chat 时，还会连接该文件夹，并向首个 thread 的草稿加入原生文件夹引用。每个 Chat 拥有独立的 thread 标签、新建会话和分叉操作。

每个 thread 输入框的模式选择器复用 DSH agent preset，可切换当前空白 thread 的模式。已开始的 thread 保留原模式，菜单可以用选定的 preset 在同一 Chat 中创建新 thread。新任务的默认模式由设置页管理。

之后建立连线时，只向发起连接时选中的 thread 添加一次文件或文件夹引用卡片，显示在输入文字上方的原生附件区，不改变输入文字或项目目录。发送以当前草稿中的引用为准。移除卡片不影响图连线，成功发送后已提交引用随草稿一起清空。切换 thread 或重新加载不会从已有连线重新添加引用。

每个 Chat 采用单行头部：左侧为折叠操作，thread 标签后紧跟**新建会话**，右侧放原生工具控件。当前 thread 的下拉菜单提供对话、轨迹等可用 Conversation 视图的切换，以及**对话设置**、分叉和归档操作。设置面板在当前标签旁打开，并保持在窗口内；原生 Session 操作和工具分区排列。Escape 和关闭按钮将焦点返回标签下拉按钮。thread 标签与画布标签共用拖拽、边缘滚动、Escape 取消及 Alt+ArrowLeft、Alt+ArrowRight 键盘排序。标题长短不同的 thread 标签在画布缩放后也可向两侧排序。每个 Chat 在当前窗口内保留独立排序，排序保留当前选中的 thread 及其草稿。

归档复用 DSH 的运行中任务确认、结果提示及撤销操作。归档成功后，该 thread 从 Chat 中隐藏，已保存的绑定和画布连线保持不变。所有 thread 均已归档时，Chat 会准备新的 thread 和输入框。恢复 thread 后，其标签回到保存的顺序。

Chat 正文使用文本光标，支持原生文字选择和复制；头部保留拖拽光标，拖动头部可移动卡片。原生输入框位于 Chat 卡片下方，不另显示项目选择器或品牌介绍。Chat 卡片、输入框和嵌入式工具面板共用 16px 圆角（`--dsw-radius-lg`）。空白对话正文保留最小高度。原生工具面板在对应 Chat 右侧展开，与同一节点一起移动、缩放；切换 thread 时，各自保留编辑器和工具页面。工具面板展开时不改变 Chat 高度，溢出内容在面板内独立滚动。折叠 Chat 保留草稿和运行中的任务。原生 Conversation 保留模型、权限、工具和审批交互。

拖拽 Chat 卡片右下角外侧的手柄，可以调整宽度和对话正文高度。输入框同步宽度，并随内容自然增高。Chat 在加载中或加载失败时仍可调整尺寸；折叠时只调整宽度，保留正文高度。右侧工具面板的高度与 Chat 头部及对话正文一致，不包含输入框；拖拽其右边缘可以调整宽度。尺寸手柄贴近卡片边缘，不显示按钮背景。手柄在悬停对应卡片时立即显示，拖拽及键盘聚焦期间保持可见。离开卡片后短暂保留再渐隐，透明操作区域仍可悬停；不支持悬停或使用粗指针的设备始终显示手柄。聚焦手柄后可用方向键调整。每个 Chat 的尺寸及工具面板的普通、展开宽度分别保存在当前窗口偏好中，同一 Chat 的所有 thread 共用这些偏好。

创建或删除未确认时，**重试**会继续原操作身份。删除包含 thread 的 Chat 或画布前，需要确认停止并归档这些 thread。

插件不可用或节点数据不兼容时，画布显示占位节点。已保存的数据、位置和连接保持不变；其他节点继续可用，占位节点仍可移动或移除。重新启用兼容的 Host 和 Client 实现后，会恢复原有显示。缺少 Client 显示实现不影响 Host 提供者准备输入。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

渲染器向外壳的单一 `shell.workspace` Slot 提供内容。组件接收派生的 Slot 属性、已声明的视图 Store 操作和窄注入回调。生成的 Remote 方法将带版本号的命令发送到 Host；Client 资源提供者负责工作区实时快照和文件读取。React Flow 处理图形交互，持久画布记录由 Host 管理。节点测量值保存在渲染器临时状态中；受控节点更新保留这些值，避免选择或属性刷新时隐藏已挂载的编辑器。

工作区控件从同一个活动操作类型派生忙碌状态和历史操作指示，同步提交保护负责阻止重叠修改。粘贴与创建副本共用同一个提交后顺序：恢复卡片偏好，选中副本，再按测量尺寸将其显示到视口中。

Desktop 拖放通过 Convax 自有适配器使用现有 preload 文件路径能力。适配器保留原始 File 身份，不改动文件字节；Host 文件系统先授权并判断解析路径的类型，再保存引用节点。通过服务访问的 Web 文档不具有原生路径能力。

窗口镜像所有者串行处理 Desktop 来源准备和 `getDisplayMedia`，以节点及绑定身份保留流。视图只挂载到该节点，复制节点不能借用采集。原生来源 id 和租约属于运行时。类型化输入触发器准备将已捕获 reference 解析成提交拥有的文本及 PNG 图片，不修改草稿附件 id。焦点或可见性恢复、指针进入时重新校验展示来源；接受像素前后，采集仍独立校验。释放时先停止轨道，再等待画面消费者，最后释放原生租约。

标题栏在 DOM 中位于画布正文之后，避免被裁剪的 `no-drag` 区域覆盖窗口拖动；Flex 顺序与 `reading-flow: flex-visual` 仍保持标题栏在视觉及键盘导航顺序中优先。

[视图 Store](src/client/store.ts)拥有标签页顺序、已关闭标签页历史、输入模式偏好、各画布独立的视口位置，以及各节点的资源展开状态、宽度与预览高度。可选的 `resourceViews` 条目及尺寸字段保持旧窗口偏好有效，并在工作区协调提供剩余节点身份时清理。Host 拥有画布文档及其原子版本。插件卸载会移除 Remote 贡献、资源提供者、活动监听流和工作区入口。

Chat 内容在显式保留的 Session provider 下使用公开的 `conversation.header.content` 与 `conversation.content` Factory。`convax.chat.content` Factory 接收 Chat 元数据、画布修订号以及节点局部的聚焦和移除操作；注入的 thread 操作负责创建与分叉。会话资源拥有可见引用；DSH 的 Conversation 草稿所有者独立保留未发送文本、附件对象及未确认的发送，因此关闭视图后仍可恢复。会话顺序、选择和待确认的创建请求使用独立的窗口偏好；已归档会话的身份保留其保存的位置。Host 拥有唯一 Session 绑定和耐久创建回执，因此重试使用实际已创建的同一 Session。

公开的 `convax.graph` Factory 与 Chat 内容共享同一份 Chat 偏好 Store。图仅为复制读取卡片尺寸、折叠状态和工具面板宽度，新卡片通过声明的 Store 操作获得这些展示偏好。thread 选择、Session 绑定、草稿和打开的工具页面不会复制。

Client 节点插件注入 `convaxRenderer` 并调用 `registerNodeRenderer(typeId, { dataVersion, component })`。返回的释放函数与贡献者的 Cordis effect 共同拥有注册生命周期；重复的活动标识会被拒绝。内置引用和 Chat 也使用同一接口。组件接收框架派生的节点属性、具名端口、绑定当前版本的命令回调及 Factory 渲染能力。需要额外状态、本地化或子 Slot 时，插件可以提供自己的 Factory。`NodePorts` 渲染已声明端口及保留连接的端点。

只有 Host 定义存在、数据版本匹配且 Host 未报告迁移或兼容问题时，节点才会传给业务渲染器。Client 显示实现也必须支持相同的数据版本。缺少显示实现、提供者不可用及数据不兼容分别显示本地化占位；占位节点的连接点保留已有连线，但不允许建立新连接。

</details>

<a id="model-experience"></a>
## 模型体验

通过原生 DSH Conversation 提交间接到达模型，其中保留的窗口 reference 加入不可变 PNG 图片及来源名称、采集时间和尺寸。

#### KV 缓存影响

窗口截图及元数据增加用户输入大小，不改变模型前缀。排队投递和重试保留同一组已接纳图片。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 音频与视频编解码支持取决于浏览器和操作系统；不支持的格式使用系统打开。文件移动和重命名不会重写已保存的引用。每个 Client 中，同一 Session 只有一个可编辑输入框；不同会话提供独立编辑器。DSH 客户端保持加载时，浏览器持有的草稿附件对象会在关闭视图后保留，但不会在页面刷新或退出应用后持久保留。
- 窗口镜像需要 macOS Desktop 屏幕采集权限；Chat 截图需要支持图片输入的模型。镜像内直接操作仍推迟实现。最小化或关闭窗口后，Chromium 轨道可能仍标记为 live；原生校验拒绝其截图，并断开已检测失效的来源。焦点、可见性、指针进入和提交是检测时机，不是持续窗口变化订阅。普通浏览器不能悄悄采集 Desktop Host 的窗口。
