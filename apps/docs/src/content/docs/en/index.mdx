Convax is an infinite canvas workspace built on DeepSeek Harness. Place resources beside the conversations that use them, connect related cards, and keep several projects visible without combining their conversation histories.

## Start with one project

[Set up Convax](/en/getting-started/), add a project folder, and choose **New chat** on its card. The Chat uses that folder as its working directory and receives a removable folder reference in its first thread's composer. Send a question from the existing DSH input to begin.

A Chat can contain several threads. Each thread keeps its own conversation, draft, model controls, permissions, and tools. Connections help arrange the work; the references currently in the input determine what accompanies a message.

Connect a window to a Chat for fresh screenshots. The agent can operate applications through the separate DSH Computer Use capability when its mode and permissions allow it.
