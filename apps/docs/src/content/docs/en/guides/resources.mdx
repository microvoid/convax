File and folder cards reference existing paths. Adding a card does not copy the source into the canvas database, and removing a reference does not delete the original file.

## Add and inspect resources

Open **+** in the creation dock and choose **Add folder** for a folder or **Add files** for one or more files. Desktop also accepts drops from the system file manager. Web can only reference paths that its Host can resolve; browser drops without a Host path report an error instead of inventing a filesystem location.

Expand a card with its arrow. Folder cards load opened directory levels on demand. Closed branches stop their expanded-directory listeners. If reading fails, available content stays visible with a Retry action.

Select a resource to reveal its toolbar. Use **Show in file manager** to locate the source. The zoom action opens a larger file preview or fits a folder card into view. The grip outside the lower-right corner adjusts card width and preview height; a collapsed card changes width while retaining its expanded height.

## Preview formats

| Content | Presentation |
| --- | --- |
| Text, code, Markdown, static HTML | Embedded document preview |
| Images, PDF, spreadsheets | Format-specific document preview |
| Word and PowerPoint | PDF presentation when an Office conversion provider is active |
| Audio and video | Browser playback with seeking and volume |

Previews load content while open and do not create a conversation or an extra tool tab. Document reads have size limits; unsupported conversion or denied filesystem access is reported locally. Renaming or moving a source does not rewrite its saved path, so re-add a reference when its location changes.

## Control playback

Hovering starts a media preview; leaving pauses it. Select **Play** when paused, or **Keep playing after the pointer leaves** during hover playback, for continuous playback. It can continue when the card collapses or you switch canvases. Use **Pause**, including the background playback control, to stop it.

The larger preview shares the same player and playback position. If the browser blocks autoplay, use manual Play. Codec support follows the browser and operating system; unsupported formats offer opening in a system app without transcoding.

To use a resource in a conversation, [connect it to a Chat](/en/guides/chats/). The composer reference, rather than the presence of a card alone, controls what accompanies a send.
