画布保存卡片与连线。顶部标签是已保存画布的一个视图；关闭标签不会删除图，之后仍可重新打开。

## 导航与排列

在左下角选择**触控板模式**或**鼠标模式**。macOS 默认触控板模式：双指滑动移动画布，捏合缩放。其他平台默认鼠标模式，使用滚轮缩放、拖拽平移。手动选择的模式会跨画布和客户端重启保留。

拖动卡片的名称区域即可移动。吸附辅助线帮助对齐相邻卡片的边缘和中心，多选卡片移动时保留相对位置。使用卡片右下方的外置手柄调整尺寸。展开内容在卡片内部滚动，原生编辑器与 Chat 历史保留各自的滚动和文字选择。

画布拥有键盘焦点时：

| 操作 | 快捷键 |
| --- | --- |
| 选择全部卡片 | Cmd/Ctrl+A |
| 复制、粘贴、创建副本 | Cmd/Ctrl+C、Cmd/Ctrl+V、Cmd/Ctrl+D |
| 分组／取消分组 | Cmd/Ctrl+G／Cmd/Ctrl+Shift+G |
| 移动所选卡片或分组 | 方向键 |
| 移除所选卡片或连线 | Delete 或 Backspace |
| 撤销／重做图编辑 | Cmd/Ctrl+Z／Cmd/Ctrl+Shift+Z |
| 适应画布 | Cmd/Ctrl+0 |

输入框、对话控件、终端、菜单和输入法组合输入仍使用自身的按键行为。撤销只处理图编辑，不会撤回已发送的消息或文件系统写入。

## 将卡片分组

选择至少两张卡片，在多选工具条或右键菜单选择**将所选节点分组**。拖动分组标题可移动整组，并使用吸附辅助线。分组框随当前卡片尺寸变化；各张卡片仍可独立编辑、移动和调整尺寸。

双击分组标题或选择**重命名分组**修改名称。卡片右键菜单提供**加入分组**和**移出分组**。拖过分组框不会改变归属。分组不能嵌套、折叠或连同内容一起缩放。

**取消分组**保留卡片与连线。**删除分组及内容**移除成员，删除 Chat 时沿用停止并归档的确认流程。复制或创建完整组成员的副本时，保留组名并创建新的分组身份；只复制部分成员时，副本成为独立卡片。分组编辑支持图撤销和重做。

## 管理已保存的画布

拖动顶部标签可以排序，双击标题可以重命名。工作区菜单中的**全部画布**提供搜索，以及使用中和已归档的两个列表。

- **归档**关闭标签，但不会停止对话；取消归档后可以重新打开。
- **复制画布**创建独立的卡片和连线标识。文件路径仍是引用，不会复制原有对话历史或草稿。
- **永久删除…**需要确认。它会移除画布及撤销历史，停止并归档其中的对话，保留原始文件和 Session 历史。

删除尚未完成时，使用保存操作提供的**重试**继续。

## 找到正在进行的工作

**活动**汇总完成通知与待交互事项。点击通知会打开对应画布并定位 Chat thread；只有成功定位后才标记已读。**自动化**会在画布上方打开 DSH 任务管理器，并能定位任务关联的对话。
