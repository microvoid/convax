窗口镜像适用于 macOS Desktop，把显式选定的应用窗口显示为只读卡片。镜像不会向原窗口转发点击或键盘输入，也不传输音频。

## 添加与重连窗口

1. 在底部创建栏选择**应用窗口**。
2. 根据应用图标和标题找到具体窗口。
3. 选择窗口；macOS 要求时，为负责采集的 Desktop 应用授予屏幕录制权限。
4. 像其他资源卡片一样排列或调整镜像尺寸。

断开的卡片提供**重新连接**与**选择其他窗口**。在当前 renderer 生命周期内，重新连接会重试保留的精确来源，保留卡片与连线，不会替换为同名窗口。复制卡片或重启客户端后，需要显式重新选择；没有运行时来源标识时，重新连接会打开选择器。

移除或重新绑定卡片会停止其采集。折叠卡片或切换画布只释放视图，仍为未发送引用保留采集。

## 发送新截图

将镜像连到 Chat，或点击其卡片上的**新建聊天**。输入框会获得可删除的窗口引用。发送时采集新图像，通过原生 DSH 附件提交；所选模型需要支持图像输入。

排队消息保留提交时的图像，历史也独立保存已提交的截图。删除引用不会删除连线。采集失败时会保留原生草稿，不会发送旧画面。

窗口最小化或不可用时，先恢复窗口、检查屏幕录制权限，再重试或重新选择。来源会在焦点、可见性、指针进入和发送等节点验证，并非持续订阅所有窗口变化。

## 让智能体操作应用

DSH **Computer Use** 与镜像是两项独立能力。启用该插件，在默认组合中使用 **PTC** 预设的 thread，并授予所需的 macOS 辅助功能、屏幕录制及应用访问权限。

已开始的 thread 保留其预设，需要时应新建 PTC thread。使用镜像不需要修改默认工具挂载规则。桌面锁定时，需要先解锁，才能继续原生观察或输入。

Windows 和普通浏览器客户端不提供这项原生镜像能力。模式选择见 [Chat 与引用](/zh/guides/chats/)，独立授权机制见 [DSH Computer Use 文档](https://github.com/microvoid/convax/blob/main/libs/dsh/packages/experimental/cua/README.zh.md)。
