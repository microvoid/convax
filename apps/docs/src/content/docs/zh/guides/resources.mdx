文件和文件夹卡片引用已有路径。添加卡片不会把源文件复制到画布数据库，移除引用也不会删除原始文件。

## 添加与查看资源

打开底部创建栏的 **+**，选择**添加文件夹**添加文件夹，或用**添加文件**选择一个或多个文件。Desktop 也接受从系统文件管理器拖入。Web 只能引用 Host 能解析的路径；浏览器拖放没有提供 Host 路径时会报错，不会虚构文件系统位置。

点击箭头展开卡片。文件夹卡片按需加载已打开的目录层级，关闭分支后释放相应的展开目录监听。读取失败时保留可用内容，并提供重试操作。

选中资源会显示工具栏。使用**在文件管理器中显示**定位源文件。放大操作会打开更大的文件预览，或将文件夹卡片适应到视野中。右下方外置手柄可以调整卡片宽度和预览高度；折叠卡片只调整宽度，保留展开时的高度。

## 预览格式

| 内容 | 展示方式 |
| --- | --- |
| 文本、代码、Markdown、静态 HTML | 内嵌文档预览 |
| 图片、PDF、电子表格 | 对应格式的文档预览 |
| Word 和 PowerPoint | 启用 Office 转换提供方后以 PDF 展示 |
| 音频和视频 | 浏览器播放，支持跳转与音量控制 |

预览在打开时加载内容，不创建对话或额外的工具标签。文档读取有大小限制；转换不可用或文件访问被拒绝时，会在本地显示错误。源文件移动或改名不会更新已保存的路径，位置改变后需要重新添加引用。

## 控制播放

悬停会开始媒体预览，离开后自动暂停。暂停时点击播放，或在悬停播放期间开启离开后继续播放，即可持续播放；折叠卡片或切换画布后也能继续。使用暂停操作或画布外的后台播放控件停止播放。

放大预览与卡片共享播放器和进度。浏览器阻止自动播放时，可以手动播放。编解码支持取决于浏览器和操作系统，不支持的格式可交给系统应用打开，不进行转码。

需要在对话中使用资源时，将其[连接到 Chat](/zh/guides/chats/)。发送消息携带哪些内容，由输入框中的引用决定；画布上存在卡片本身不会自动添加上下文。
