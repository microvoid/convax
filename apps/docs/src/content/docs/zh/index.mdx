Convax 是基于 DeepSeek Harness 的无限画布工作台。把资源放在使用它的对话旁边，通过连线组织任务，在同一视野中处理多个项目，同时保留各自独立的对话历史。

## 从一个项目开始

先[完成安装](/zh/getting-started/)，添加项目文件夹，再点击文件夹卡片上的**新建聊天**。Chat 将该文件夹作为工作目录，并在首个 thread 的输入框中加入可删除的文件夹引用。通过原有的 DSH 输入框发送问题，即可开始。

一个 Chat 可以创建多个 thread。每个 thread 保留自己的对话、草稿、模型选择、权限和工具。连线用于组织工作；发送消息时携带哪些资源，以输入框当前保留的引用为准。

以下界面演示展示项目协作与应用操作流程。

### 多项目并行

把独立项目及其对话放在同一画布上。点击预览可打开完整中文视频。

### 通过对话操作应用

将窗口连到 Chat，发送消息时采集新截图。启用独立的 DSH Computer Use 能力，并满足模式与授权要求后，智能体可以操作应用。
